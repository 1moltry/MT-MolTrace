# MOLTRACE — 单分子纳米孔电流信号分析

**MOLTRACE** MT by 1moltry for Huang Lab：纳米孔数据处理平台，基于此的多算法开发实现更定制化的事件查找、指纹处理、自动化流程

它读取 `.abf` 电流记录，自动完成事件分割与特征提取，可选做异常筛查，并导出 Excel、图片和 MATLAB 数据。软件在本机运行，数据不上传。

当前版本 `v3.1.0`。仓库：<https://github.com/1moltry/MT-MolTrace>。

## 下载使用

1. 打开 [Releases](https://github.com/1moltry/MT-MolTrace/releases)，在最新版本下方的 **Assets** 下载 `MOLTRACE_v3.1.0_win64.zip`。
2. 右键 zip，选择“全部解压缩”，解压到硬盘目录，例如 `D:\MOLTRACE`。
3. 双击 `MOLTRACE.exe` 启动。
4. 首次运行若提示“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。

> `MOLTRACE.exe` 与 `_internal` 文件夹必须放在同一层。只把 exe 单独拷走，程序无法启动。

完整的使用教程见 [tutorial.md](tutorial.md)，发行包内也附带同一份。

## 核心功能

- **事件检测**：电平法、驻留包络、平台滞回三种算法，可并排对比。
- **特征提取**：输出 20 列事件特征表，含阻孔比、驻留时间、偏度、峰度等。
- **异常处理（可选）**：默认关闭；检测后识别反压恢复、膜抖动、基线漂移、炸膜等区间。只剔除已检出事件，不改变三种检测算法的事件边界。
- **批量处理**：整个文件夹一次导出，可选事件波形、图片、批次汇总与合并训练表。
- **事件指纹（分段）**：可选把每个保留事件切成若干段，生成 `*_fingerprints.xlsx` / `.json`。描述器由注册表提供：`dp_bic`（DP+BIC 台阶，测试）、`classic`（双阈值候选，测试）、`scalar`（标量对照）；界面可并排比较两种描述器，也可单独导出当前文件。每个事件带稳定事件键与全局采样坐标，可与事件波形表互相回溯。**指纹分类/识别本身尚未实现。**
- **指纹研究（实验性，默认关闭）**：从多个 `.abf` 的事件体拟合可变长度形状词表（PELT 变点 + DTW/Fréchet/DBA），支持词表保存/加载与叠加解码。旧词表的合成对照 AUC 为 0.674 / 0.715，低于计划门槛 0.85；结果只能用于探索，不得当作结论。
- **可视化**：全程波形、事件切片、深度-时长散点与直方图，点击事件表联动定位。

## 开发哲学

- **超越、个性化的操作平台**：算法适应课题组新时代数据，结果可对照。
- **平台作为起点**：适配不断进化的算法的功能性平台。
- **单一底座，按需启用模块**：不同类型数据，一个界面，多个算法。
- **本地运行，安全、可靠**：数据不出本机；进入剔除表的事件都能查到原因与阶段。
