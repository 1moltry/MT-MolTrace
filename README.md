# SDL 纳米孔数据分析

打开一个 `.abf` 电流记录，自动完成事件分割、特征提取和异常剔除，并导出 Excel、图片和 MATLAB 数据。

软件在本机运行，数据不上传。免安装包支持 Windows 10/11 64 位，不需要安装 Python。

## 下载与安装

1. 打开 [Releases 页面](https://github.com/1moltry/SDL-Auto-Data-process/releases)。
2. 在 **Assets** 里下载最新发行包（包名形如 `SDL纳米孔分析_v3.0.0_win64.zip`；当前代码版本为 `v3.0.0`，发行包以 Releases 页面为准）。
3. 下载完成后，右键 zip 文件，选择“全部解压缩”。
4. 打开解压后的文件夹，双击 `SDL纳米孔分析.exe`。

第一次运行 Windows 可能弹出“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”。程序没有数字签名，这是正常提示。

> **不要只把 exe 拷走。** exe 旁边的 `_internal` 文件夹必须保留，否则程序无法启动。
>
> 建议解压到硬盘目录，例如 `D:\SDL纳米孔分析`。解压后约 250 MB。
>
> 如果 Releases 页面还没有安装包，请在 [Issues](https://github.com/1moltry/SDL-Auto-Data-process/issues) 留言，或向实验室同事索取 zip。

## 第一次使用（5 分钟）

1. 双击 `SDL纳米孔分析.exe`，进入**首页工作台**。
2. 选择一种任务：
   - **单文件分析**：打开一个 `.abf`，查看波形和事件。
   - **批量处理**：选择文件或文件夹，用同一套参数导出。
   - **算法对比**：同一文件并排比较三种检测算法。
   - **使用教程**：打开完整教程。
3. 在分析界面，顶部“检测算法”选择电平法 / 驻留包络（burst）/ 平台滞回；右侧参数只显示当前算法的参数。
4. 点“算法对比…”可以并排看三种算法的数量与边界差异。
5. 要导出结果，点“批量处理…”，添加文件或文件夹，选择输出目录，点“开始处理”。

单文件界面只用于查看，不写文件。导出要走“批量处理…”。

## 界面一眼看懂

| 位置 | 内容 |
|------|------|
| 首页工作台 | 单文件分析、批量处理、算法对比、使用教程；下方是最近打开的文件 |
| 顶部工作栏 | 首页、打开、当前文件、检测算法、算法对比、批量处理、结果摘要 |
| 中间上方 | 完整电流波形，蓝色线标出检出的事件 |
| 中间下方 | 选中事件的放大切片 |
| 左侧“事件”表 | 保留的事件，一行一个，带 State 筛选 |
| 左侧“异常事件（剔除）”表 | 被剔除的事件和原因；默认隐藏，从“视图”菜单打开 |
| 右侧“参数” | 当前检测算法的参数、基线与预处理、模块；按功能分组 |
| 右侧“统计” | 事件时长直方图、SD-|ΔI| 散点图；默认隐藏 |

主图操作：滚轮缩放，左键拖动平移，右键拉框放大，单击选最近的事件。“全览”回到完整波形。

## 三种事件检测算法

右侧“参数 → 检测算法”可选：

| 算法 | 适合 | 特点 |
|------|------|------|
| 电平法（Clampfit 语义） | 常规单通道、多电平、肽 | 逐样本归到最近电平，边界在 50% 交叉 |
| 驻留包络（burst） | 抖动、毛刺、基线上下跳 | 把一次阻孔内的碎片合并成一个事件 |
| 平台滞回（sweep/plateau） | 糖、长阻孔、事件内有部分恢复 | 边界贴近开孔，部分恢复不切碎事件 |

平台滞回的默认参数按糖数据标定（进入 60 pA、退出 15 pA、短开孔 1 ms）。换数据集时，先在单文件里看波形和事件表，再批量处理。

三种算法共用同一套后处理、特征表和导出格式；切换算法不会改变输出文件的结构。

## 算法对比怎么用

1. 打开一个文件，或从首页点“算法对比”再选文件。
2. 勾选 2–3 种算法，点“开始对比”。
3. 表格看：原始/保留事件数、中位驻留、中位深度、用时、与基准算法的匹配数和边界差。
4. 图上彩色标记是各算法的事件起点和终点；滚轮缩放即可看局部差异。
5. 选中表格一行，点“用选中算法查看”，回到分析界面用该算法重跑。

对比只读，不写事件表；确定算法后再走“批量处理”导出。

## 输出什么

每个 `.abf` 至少生成一个事件表。勾选模块后，还会生成图片、MATLAB 波形和批次汇总。

| 文件 | 内容 | 何时生成 |
|------|------|----------|
| `<文件名>_events.xlsx` | 事件特征表；另有 `excluded`、`anomalies` 工作表 | 总是 |
| `<文件名>_events.mat` | 每个事件的原始电流序列 | 勾选“事件波形导出” |
| `<文件名>_overview.png` | 全程波形、事件标记、异常区间 | 勾选“输出图” |
| `<文件名>_scatter.png` | 深度-时长散点等 | 勾选“输出图” |
| `<文件名>_hist.png` | 深度和时长直方图 | 勾选“输出图” |
| `summary.xlsx` | 每个文件一行的事件数、有效率、异常计数 | 勾选“批次汇总” |
| `dataset_all.csv` | 所有文件的保留事件合并表 | 勾选“合并训练表” |

## 常见问题

**双击没有反应？** 确认 zip 已完整解压，exe 和 `_internal` 在同一层。不要只拷 exe。若仍无反应，打开命令提示符，把 exe 拖进去后回车，查看报错。

**为什么没有图？** 默认只导出事件表。在“参数 → 模块”里勾选“输出图”。

**为什么没有事件？** 先看波形有没有明显阻孔，再检查检测模式、Level0/Level1 和阈值。可以点“全览”确认数据已加载。

**结果准不准？** 算法有实验室样例回归测试，但自动检测总有边界情况。正式统计前，请抽查波形、事件表和剔除表。

**数据会上传吗？** 不会。软件只在本机读写文件。

**支持 Mac 或 Linux 吗？** 免安装包是 Windows 64 位。其他系统可以从源码运行，见 [DEVELOPMENT.md](DEVELOPMENT.md)。
