# SDL 纳米孔数据分析

打开一个 `.abf` 文件，自动完成事件分割、特征提取、异常剔除，并导出事件表、波形图与散点图。

本软件替代原来的手工流程「Clampfit 手动找事件 → MATLAB 提特征 → Origin 作图」，把一次分析从几十分钟压缩到几秒。

## 快速上手

1. 解压整个文件夹。**exe 和它旁边的文件要放在一起**，不要只把 exe 拷走。
2. 双击 `SDL纳米孔分析.exe`。
3. 点工具栏「打开」，选一个 `.abf` 文件，波形和事件表立刻显示。
4. 要导出结果，点工具栏「批量处理…」，添加文件或文件夹，选输出目录，点「开始处理」。

第一次运行 Windows 可能弹出「已保护你的电脑」：点「更多信息」，再点「仍要运行」。程序没有购买数字签名，这是正常提示。

## 界面导览

| 位置 | 看什么 |
|------|--------|
| 左上方「事件」表 | 检出的事件，每行一个；点击任一行，其他面板会跳到该事件 |
| 左下方「异常事件（剔除）」表 | 被剔除的事件及原因（落在异常区间、时长过短）。**默认隐藏**，从「视图」菜单勾选显示 |
| 中间上方 | 完整波形，叠加蓝色理想化事件线；滚轮缩放，左键拖动平移，**右键拉框放大选区** |
| 中间下方 | 选中事件的放大切片，看单个事件的电流形状 |
| 右侧「参数」 | 检测模式、参数、模块勾选（按功能分标签页）；**改动后自动重跑** |
| 右侧「统计」 | 事件时长直方图 + 深度-时长散点图，点散点可跳转事件。**默认隐藏**，从「视图」菜单勾选显示 |

## 怎么导出结果

界面上单个文件只是**查看**，不写文件。要导出，用工具栏的「批量处理…」：

1. 添加文件或文件夹（文件夹会递归找出里面所有 `.abf`）。
2. 选输出目录（必选）。
3. 点「开始处理」，下面是逐文件进度；结束后汇总表自动写入输出目录。

## 输出文件

每个 `.abf` 生成同名文件，具体有哪些取决于勾选了哪些模块：

| 文件 | 内容 |
|------|------|
| `<名>_events.xlsx` | 事件特征表，一行一个事件；另有「被剔除事件」和「异常区间」两个工作表 |
| `<名>_events.mat` | 每个事件的原始电流序列，供 MATLAB 直接读（需勾选「事件波形导出」） |
| `<名>_overview.png` | 全程波形 + 事件标记 + 异常区间底色（需勾选「输出图」） |
| `<名>_scatter.png` | 深度-时长散点、开孔电流-时间散点（同上） |
| `<名>_hist.png` | 深度直方图 + 时长直方图（同上） |

批次级：

| 文件 | 内容 |
|------|------|
| `summary.xlsx` | 每个文件一行：事件数、有效率、基线、异常计数、耗时（需勾选「批次汇总」） |
| `dataset_all.csv` | 所有文件的保留事件拼成一张表，供 MATLAB / 机器学习使用（需勾选「合并训练表」） |

## 常用设置

**模块（可多选，默认全关）**：软件默认只导出事件表。要图、要 MATLAB 波形、要合并表，就在右侧「参数」面板的模块区勾选；模块按「预处理 / 异常检测 / 单文件输出 / 批次输出」分标签页，切换标签不会丢失已勾选项。勾选状态会被记住。

**检测模式**：

- **电平法**（默认）：适合常规清晰的阻孔脉冲。
- **burst（驻留包络去抖）**：适合事件内部有大量毛刺回落、或电流在开孔上下跳跃的信号，会把零碎抖动合并成一个事件。

**最常调的两项**：

- 「最短事件时长 (ms)」：短于它的事件进剔除表，默认 10 ms。
- 「检测电平 level0 / level1」：留空自动估计；双态孔或双物种数据建议手动指定。

## 与 MATLAB 对接

`dataset_all.csv` 可以直接读：

```matlab
T = readtable('输出目录/dataset_all.csv');
X = T{:, {'mean','rel_mean','std','skew','kurt','toff','MAD','CV', ...
          'q1','q2','q3','iqr','outlier_ratio'}};
y = categorical(T.Label);       % 分类目标（物种 / 样本）
```

列名做了两处规范化：`%mean` 改成 `rel_mean`（`%` 不是合法变量名），`t1`/`t2` 改成 `t1_s`/`t2_s`（单位是秒，原规范是毫秒）。做特征时请排除 `t1_s`、`t2_s`（时间戳）和 `I0`（每条记录同一个值）。

要**每个事件的原始电流波形**，勾选「事件波形导出」，读同名 `_events.mat`：

```matlab
S = load('输出目录/Ala_events.mat');
e = S.events{1};                        % 一个事件
w = e.current_pA(:);                    % 原始电流序列，不含前后余量
t = e.t1_s + (0:numel(w)-1)'/e.fs_hz;   % 每个采样点的时间（秒）
```

## 常见问题

**双击没反应？** 确认整个文件夹都解压出来了。若仍无反应，在命令行里运行 exe，可以看到报错信息。

**生成的文件为什么没有图？** 默认只导出事件表，请在「模块（可多选）」里勾选「输出图」。

**文件名是中文可以吗？** 可以，中文路径也能正常处理。

**大文件很慢？** 30M 采样点的记录，单文件分析约几秒。批量处理时进度栏会逐个显示。

**结果准不准？** 算法在实验室样例数据上有回归测试；但自动检测总有边界情况，建议先看波形和散点图，确认无误再用于统计。
